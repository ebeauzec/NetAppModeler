ℹ️ How to collect and upload Multi-Node AutoSupport bundles?

Consolidation & Merge Logic: AutoSupport messages are typically generated at the individual node level. If your cluster contains multiple nodes, you can select and upload the ASUP files or compressed archives (.zip or .gz) for all nodes together. The modeler automatically parses, concatenates, and de-duplicates storage controller nodes, switches, shelves, drives, aggregates, and spares to build a consolidated, unified cluster-wide view.

Supported Ingestion Formats: Raw text files extracted from AutoSupport mail bundles or compressed zip/gz archives containing the following ONTAP diagnostic outputs:

  • VERSION - Identifies the active ONTAP software release and system model type.
  • SYSCONFIG-A - Extracts motherboard RAM capacity, CPU counts, PCIe slots, cabled shelves, and disk details.
  • SYSCONFIG-R - Discovers aggregate layouts, RAID groups, spare allocations, and disk-level firmware.
  • LICENSE - Checks for active, expired, or missing feature licenses.
  • NETPORT - Captures physical network interfaces, negotiated link speeds, and MTU values.
  • METROCLUSTER-SHOW - Detects DR configuration types (MetroCluster IP or FC).
  • SWITCHES - Discovers cluster switches cabled and Reference Configuration File (RCF) versions.

Manual Log Collection Options:
• System Manager (GUI): Navigate to Cluster > Support > AutoSupport, select nodes, and select Invoke to send or download logs.
• ONTAP CLI (SSH): Run system node autosupport invoke -node * -type all -message "manual" to generate logs, or run individual commands (like sysconfig -a or sysconfig -r) to capture text blocks.

Model Storage Capacity & Hardware Expansion

💡 What is a disk shelf? A disk shelf is a rack-mounted unit (typically 2U or 4U tall) that holds disk drives. Adding shelves increases your storage capacity. Select the type that matches your platform — different controllers support different shelf types.
NS224 = NVMe SSD shelves (fastest, all-flash). DS224C = SAS SSD/HDD shelves (high capacity). DS460C = High-density SAS HDD (maximum raw capacity, 60 drives).
💡 Select the drive capacity and type to populate this shelf with. Larger drives = more capacity but similar cost per drive. All drives in a shelf must be the same type. Mix different drive sizes across shelves, not within a shelf.
💡 You don’t have to fill a shelf completely. However, keep at least 2 drives as spare reserves — spares allow automatic recovery if a drive fails. Fewer spares = higher data loss risk.
-
💡 What happens to the new drives?
  • Add as Spare Reserves — Drives sit ready but unused. If a production drive fails, a spare automatically replaces it. No new usable capacity is added.
  • Expand Existing Aggregate — Add drives to an existing storage pool to increase its size. Good for growing a volume that is running out of space.
  • Create New Aggregate — Create a new independent storage pool from the new drives. Good for separating workloads or supporting a new project.
💡 Aggregate name: Use a descriptive name like aggr1_node1. Avoid spaces and special characters.
RAID-DP (recommended) = 2 parity drives protect against 2 simultaneous disk failures. RAID-TEC = 3 parity drives, use for very large disks (10TB+). RAID-4 = legacy, 1 parity, avoid unless required.
RAID group size: Typically 16–20 for SSD, 12–16 for HDD. Larger groups = more capacity efficiency but slower rebuild if a drive fails.
Allocated: 0 / 24 drives. (Remaining drives will go to Spare Reserves).
💡 What is a PCIe card? Expansion cards add new capabilities or ports to the controllers. Common types:
  • Storage HBA (Host Bus Adapter) — Adds extra SAS or NVMe ports to connect more disk shelves than the onboard ports support.
  • FC (Fibre Channel) — Adds high-speed SAN connectivity for block-storage clients (VMware, databases).
  • Ethernet (10/25/100GbE) — Adds network ports for NAS (NFS/CIFS) data traffic or cluster interconnect.
  • NVMe-oF — Adds ultra-low-latency NVMe over Fabrics connectivity for the highest-performance workloads.
⚠️ Installing PCIe cards requires controller shutdown and HA takeover — this is a physical, hands-on operation. Plan for a maintenance window.
